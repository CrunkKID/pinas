So kommst du an ein Update
  1. Auf GitHub im Repository unter Actions → „PiNAS-Update bauen“ → „Run workflow“ starten (dauert unter einer Minute).
  2. Im fertigen Lauf unten unter Artifacts die Datei pinas-update-… herunterladen.
  3. Die ZIP-Datei so wie sie ist oben auswählen oder hineinziehen → Prüfen → Jetzt installieren.

Wird auf GitHub ein Release (z. B. v1.3.0) veröffentlicht, findet „Nach Updates suchen“ das Paket auch direkt.
